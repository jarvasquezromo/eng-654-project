Grid

Contour shape, orientations, height and grid ranges are set in Step 6. Changes here are shared with Steps 5 and 6.

Per placement

The contour is sampled at N poses. All IK candidates are computed at each one. Each start configuration at s = 0 (each candidate within limits, and each physical q₆ representative) is a separate start; its branch label is the one at s = 0.

Nearest continuation

From the current q, take the candidate at the next sample that is closest on the joint torus and unwrap it next to q. Tests in order: loss of IK (no candidate at that sample), discontinuity (closest candidate further than Δqmax), joint limit (unwrapped q outside the URDF range), singularity margin (1/κ below the threshold). The first failing test along the loop is the reason; success means all N steps back to s = 0.

Branch-aware search

A layered graph over all samples: nodes are physical configurations within limits and margin, edges join consecutive samples when every joint moves ≤ Δqmax. A start succeeds if any node of the last layer (the start pose again) is reachable. It keeps alternatives instead of committing to the nearest candidate.

Reading the summary colour

Green: at least one start completes (darker = more). Otherwise the colour is the reason of the start that got furthest. Grey: some sample has no IK at all. Light hatched: the selected start branch does not exist at s = 0 there.
