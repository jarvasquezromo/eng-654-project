Step 3 · Differential kinematics

Screw Jacobian and ³J₅

Each column is one joint's screw axis seen from a reference point. Pick a column to see it on the robot.

\(J_i = \begin{bmatrix}\omega_i\times(p-r_i)\\ \omega_i\end{bmatrix}\): angular velocity \(\omega_i\) along the current joint axis, and the linear velocity it induces at the tool point \(p\) (lever arm \(p-r_i\)). Built from the space Jacobian \(J_s=[\mathrm{Ad}_{T_{1..i-1}}S_i]\).

Course definition: the same joint screws, taken about the D–H origin \(O_5\) and resolved in frame {3}: \({}^3J_5=\operatorname{diag}(R_{03}^\top,R_{03}^\top)\,{}^0J_{O_5}\). Shaded: the upper-right 3×3 block, which is zero for a spherical wrist.

Reading the blocks for GoFa

Linear rows are divided by a characteristic length \(L\) so metres and radians are comparable. Then \(\kappa=\sigma_{\max}/\sigma_{\min}\) and \(w=\prod\sigma_i\).

Singular values of the scaled Jacobian
\(\det J\) is the same for every reference point and every basis: \(\det({}^3J_5)=\det({}^0J_{\text{tool}})\). Changing the point multiplies by a unit block-triangular matrix, and changing the basis by \(\operatorname{diag}(R^\top,R^\top)\). Singularity is a property of the configuration, not of where you measure.

Each column is compared with a central finite difference of the PoE forward kinematics (\(h=10^{-6}\)): \(\dot p\) for the linear rows and \(\mathrm{vee}(\dot R R^\top)\) for the angular rows.
