Contour

\(p(s) = c + R_g\,[a\cos s,\ b\sin s,\ 0]^\top\), \(R(s) = R_g\,R_z(\psi\sin s)\,R_x(\theta\sin s)\,R_y(\theta\cos s)\), \(s \in [0, 2\pi)\), sampled at \(N\) points. \(R_g\) is the global tool orientation, \(\theta\) the tilt, \(\psi\) the spin. Both position and orientation are \(2\pi\)-periodic, so the pose path is closed.

Placement family

The contour centre \(c = (x, y, z_0)\) moves on an \(n\times n\) grid over \([x_{\min}, x_{\max}]\times[y_{\min}, y_{\max}]\) at fixed height \(z_0\). Shape, orientation profile and \(R_g\) stay the same, so every placement is the same task translated. The study is repeated for two global orientations A and B.

Per placement

All IK candidates are computed at every sample. Each start configuration at \(s=0\) is followed around the loop (nearest continuation and branch-aware search, Step 7). The robot animation here uses nearest continuation from the selected start.
